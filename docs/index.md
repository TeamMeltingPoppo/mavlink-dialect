# MAVLinkプラットフォーム

TeamMeltingPoppoで使用するMAVLinkプラットフォームのドキュメントです。

MAVLinkの定義、各言語での実装、ファームウェア開発用テンプレート、開発ツールを複数のリポジトリに分けて管理しています。

## 全体像

このプラットフォームの構成と、各リポジトリの関係については[アーキテクチャ](architecture.md)を参照してください。
